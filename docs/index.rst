Silex Data Ansible Collections
==============================

Documentation for every ``silexdata.*`` Ansible collection published by
`Silex Data Solutions <https://github.com/SilexDataTeam>`_, compiled nightly
from each collection's own repository.

Each collection's coverage report is kept with that collection: open a
collection below and use its **Coverage Report** button, or its Coverage
Summary page.
